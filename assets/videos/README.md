# Welcome background video

Drop a looping, muted, portrait-friendly travel clip here named **`welcome.mp4`**
(H.264 .mp4, ideally 1080×1920, a few seconds, < ~5 MB).

The Welcome screen references `assets/videos/welcome.mp4`
(see `AppConstants.welcomeVideoAsset`). If no file is present, the app
automatically shows an animated brand-gradient background instead — so the
screen always looks polished, with or without a video.

Good free sources: Pexels, Pixabay, Coverr (check each clip's licence).
